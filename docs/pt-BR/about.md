# Sobre a Finenumbers

**UFW Remote Manager** é desenvolvido pela [Finenumbers](https://finenumbers.com).

A Finenumbers cria ferramentas de comunicação empresarial. O UFW Remote Manager é um utilitário open-source auto-hospedado para equipes que gerenciam firewalls de servidores Linux via SSH.
