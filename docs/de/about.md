# Über Finenumbers

**UFW Remote Manager** wird von [Finenumbers](https://finenumbers.com) entwickelt.

Finenumbers entwickelt Business-Kommunikationstools. UFW Remote Manager ist ein Open-Source-Self-Hosting-Utility für Teams, die Linux-Server-Firewalls über SSH verwalten.
