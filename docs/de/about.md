## Über das Produkt

Finenumbers entwickelt operative Werkzeuge für Infrastruktur- und Kommunikationsteams. UFW Remote Manager adressiert ein praktisches Bedürfnis: zentralisierte, auditierbare UFW-Verwaltung über Linux-Server hinweg, ohne sich für jede Regeländerung auf jedem Host anzumelden.

Die Anwendung ist **selbst gehostet** — Ihre Daten, SSH-Zugangsdaten und Firewall-Regeln bleiben auf Infrastruktur, die Sie kontrollieren.
