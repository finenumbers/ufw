# Быстрый старт

Запустите UFW Remote Manager локально в Docker. Этот путь для **оценки и разработки**, не для продакшена.

## Предварительные требования

- Docker и Docker Compose
- Git
- Свободный порт **8088** на localhost (настраивается через `APP_PORT`)

## 1. Клонирование и настройка

```bash
git clone https://github.com/finenumbers/ufw.git
cd ufw
cp .env.example .env
```

Значения `.env` по умолчанию подходят для локального использования. Предзаполненные секреты только для разработки — сгенерируйте новые для shared или production deploy.

## 2. Запуск stack

```bash
docker compose up -d --build
```

Запускаются:

| Сервис | Роль |
|--------|------|
| **postgres** | База данных PostgreSQL |
| **migrate** | Однократно выполняет `prisma migrate deploy`, затем завершается |
| **app** | Next.js UI на порту 8088 |

Проверка статуса:

```bash
docker compose ps
docker compose logs -f app
```

## 3. Создание учётной записи администратора

Откройте **http://localhost:8088/setup**

- Регистрация доступна **только один раз** — пока нет пользователя
- После настройки `/setup` перенаправляет на login
- Используйте надёжный пароль; это единственная учётная запись администратора

## 4. Создание SSH-идентификации

1. Боковая панель → **SSH-идентификации** → **Добавить идентификацию**
2. Выберите auth: пароль, приватный ключ или ключ с парольной фразой
3. Сохраните — учётные данные шифруются с `APP_ENCRYPTION_KEY`

См. [SSH-идентификации](./concepts/ssh-identities.md).

## 5. Добавление сервера

1. Боковая панель → **Серверы** → **Добавить сервер**
2. Укажите имя, хост, порт, выберите идентификацию
3. **Создать сервер** автоматически проверяет SSH

При успехе откроется dashboard сервера. Бейдж UFW показывает кэшированное состояние (пусто до первого обновления).

## 6. Обновление и работа с правилами

1. Нажмите **Обновить статус** — live SSH read; создаёт первый UFW snapshot
2. Если UFW отсутствует, используйте **Установить UFW** (после подтверждения обновлением)
3. При активном UFW редактируйте правила в таблице
4. Предпросмотр apply → проверка → **Подтверждение** для отправки изменений

Если snapshot ещё нет, может однократно запуститься фоновый **initial sync** — см. [Управление серверами](./user-guide/manage-servers.md).

## Опционально: включить scan портов локально

Добавьте в `.env`:

```env
PORT_SCAN_ENABLED=true
```

Пересоберите/перезапустите контейнер app. Scan требует Naabu и Nmap в образе (в официальном Dockerfile включены).

## Разработка без полного Docker app

Только Postgres в Docker, app на хосте:

```bash
docker compose up -d postgres
npm install
npm run db:migrate
npm run dev
```

App слушает **http://localhost:8088** (см. `package.json`).

## Остановка и сброс

```bash
docker compose down          # остановить containers
docker compose down -v       # остановить и удалить volume БД
```
