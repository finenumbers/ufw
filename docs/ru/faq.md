# FAQ

## Общее

### Что такое UFW Remote Manager?

Self-hosted веб-приложение для управления UFW на удалённых Linux-серверах по SSH с workflow черновик/apply и audit trail.

### Заменяет ли Nginx Proxy Manager?

Нет. NPM (или аналог) завершает HTTPS для админ-UI. UFW Remote Manager управляет **межсетевыми экранами удалённых серверов**, а не вашим reverse proxy.

### Можно ли управлять Docker-контейнерами?

Нет. Мониторинг Docker-контейнеров **удалён в v0.9.0**. Приложение управляет только правилами UFW и опциональным внешним scan портов.

### Сколько admin-пользователей?

Одна учётная запись после initial `/setup`. Multi-user UI нет.

### Можно ли запускать несколько реплик app?

Не рекомендуется. Rate limits и очереди in-memory (дизайн single replica).

## SSH и серверы

### Почему отклоняется private IP?

Стандартная безопасность — блокирует RFC1918 и metadata addresses. Задайте `SSH_ALLOWED_CIDRS` для lab/VPN targets.

### Почему apply отключён?

SSH host key может быть **не проверен**. Сначала успешно выполните **Обновить статус**.

### Удаление сервера меняет remote UFW?

Нет. Удаление затрагивает только локальные данные управления.

## Правила и apply

### Preview vs confirm?

Preview показывает планируемые изменения без выполнения. Confirm выполняет команды UFW по SSH.

### Remote изменился после preview?

Apply отклонён — снова выполните **Apply preview**. Force resync в этом случае не используйте.

### Частичный apply?

См. [Черновик и применение](./concepts/draft-apply-workflow.md). Используйте **Принудительная синхронизация с сервером**, когда указано.

### Почему различаются счётчики правил?

**Сохранённые правила** (карточка списка) и **в таблице** (dashboard) считают разное — см. [Правила UFW и состояния](./concepts/ufw-rules-and-states.md).

## UI операций

### Баннер завис на ВЫПОЛНЯЕТСЯ?

Обновите страницу. Sweeper снимает stale operations за ~30–60 минут.

### Правила не обновляются после sync?

С v0.9.2 окончание операции должно обновлять страницу. Один раз обновите браузер вручную.

## Сканирование портов

### Нет кнопки scan?

`PORT_SCAN_ENABLED` не установлен в `true` в окружении app.

### Scan уже выполняется?

Только один активный scan на сервер. Дождитесь или проверьте историю операций.

### Scan блокирует UFW refresh?

Нет (с v0.9.2). Scan выполняется вне SSH-очереди.

## Развёртывание

### Где запускать migrations?

В контейнере **migrate** / **ufw-migrate** — не внутри **ufw-app**. См. [Обзор развёртывания](./deployment/overview.md).

### EACCES при prisma в app container?

Ожидаемо — используйте `docker compose run --rm migrate`.
