# FAQ

## Общие вопросы

**Что такое UFW Remote Manager?**  
Self-hosted веб-интерфейс для управления межсетевыми экранами UFW на удалённых Linux-серверах по SSH с рабочим процессом черновик/применение и журналом аудита.

**Это бесплатно?**  
Open source под лицензией MIT. Инфраструктуру (Docker-хост, домен, SSL) предоставляете вы.

**Кто это создал?**  
[Finenumbers](https://finenumbers.com) — см. [О Finenumbers](./about.md).

## Учётные записи

**Можно ли создать нескольких администраторов?**  
Через самостоятельную регистрацию — нет. Только одна учётная запись создаётся на `/setup`; дальнейшая регистрация отключена.

**Я забыл пароль.**  
Сброс требует доступа к базе данных или восстановления из резервной копии. В конфигурации по умолчанию нет сброса по email.

## Развёртывание

**Нужен ли отдельный Docker-образ для каждого домена?**  
Нет. Задайте `APP_URL` в `.env` во время выполнения. Один образ GHCR работает для любого HTTPS-домена.

**Включён ли Nginx Proxy Manager?**  
Нет. NPM (или другой reverse proxy) нужно установить отдельно.

**Можно ли работать без HTTPS?**  
Локальная разработка использует `http://localhost:8088`. Продакшен предполагает HTTPS для безопасных cookies и HSTS.

## Операции с межсетевым экраном

**Удаляет ли удаление сервера удалённые правила UFW?**  
Нет. Удаляются только локальные записи в базе данных.

**Что если применение прервётся на полпути?**  
Удалённый UFW может быть частично обновлён. Используйте **Принудительную синхронизацию с сервером** и просмотрите Историю операций. См. [Черновик и применение](./concepts/draft-apply-workflow.md).

**Можно ли управлять серверами на частных IP?**  
Да, задайте `SSH_ALLOWED_CIDRS` в `.env` для ваших внутренних диапазонов.

## Данные и безопасность

**Где хранятся SSH-ключи?**  
Зашифрованы в Postgres с `APP_ENCRYPTION_KEY`. Ключ из `.env` обязателен для расшифровки.

**Безопасен ли экспорт конфигурации?**  
Экспорт содержит **секреты в открытом виде**. Требуется повторный ввод пароля; храните экспорты в безопасном месте.
