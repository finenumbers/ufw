# Редактирование и применение правил

Когда UFW **установлен и активен** на сервере, откройте вкладку **Правила** для управления правилами межсетевого экрана.

## Таблица правил

Возможности:

- Поиск и фильтры столбцов
- Секции групп с развёртыванием/свёртыванием
- Изменение порядка перетаскиванием (порядок важен для UFW)
- Цвета строк по [состоянию синхронизации](../concepts/ufw-rules-and-states.md)
- Добавление строки, inline-редактирование, удаление строки

## Обновление с сервера

Нажмите **Обновить статус** (или используйте обновление на панели), чтобы:

1. Определить состояние UFW
2. Загрузить снимок с сервера
3. Синхронизировать исходные состояния черновика

Используйте это после ручных изменений в CLI на сервере или после частичного применения.

## Принудительная синхронизация

Если интерфейс предупреждает о расхождении или частичном применении, используйте **Принудительную синхронизацию с сервером**, чтобы заменить выравнивание локального черновика фактическим удалённым снимком перед дальнейшим редактированием.

## Импорт правил

Панель инструментов → импорт CSV, XLSX или JSON. Проверьте импортированные строки в таблице перед предпросмотром применения.

## Рабочий процесс применения

1. Внесите изменения в черновик
2. **Сохранить правила** — просмотрите запланированные команды и сводку diff
3. **Подтвердить** — выполнение по SSH
4. Следите за баннером операций для отслеживания прогресса

Подробности см. в [Черновик и применение](../concepts/draft-apply-workflow.md).

## Советы по безопасности

- Всегда оставляйте хотя бы одно правило, разрешающее SSH из вашей админ-сети, перед применением правил deny
- Запускайте предпросмотр в продакшене в окно обслуживания
- Проверяйте **Историю операций** после применения на статус SUCCESS или FAILED
