# Редактирование и применение правил

Когда UFW **установлен и активен** на сервере, откройте вкладку **Правила** для управления правилами firewall.

## Таблица правил

Возможности:

- Поиск и фильтры по столбцам
- Секции групп с развёртыванием/свёртыванием
- Перетаскивание для изменения порядка (порядок важен для UFW)
- Цвета строк по [состоянию синхронизации](../concepts/ufw-rules-and-states.md)
- Добавить строку, редактировать inline, удалить строку

## Обновление с сервера

Нажмите **Обновить** (или используйте обновление панели), чтобы:

1. Определить состояние UFW
2. Загрузить snapshot с сервера
3. Синхронизировать исходные состояния черновика

Используйте после ручных изменений на CLI сервера или после частичного применения.

## Принудительная ресинхронизация

Если интерфейс предупреждает о drift или частичном применении, используйте **Принудительная ресинхронизация с сервера**, чтобы заменить локальное выравнивание черновика фактическим удалённым snapshot перед дальнейшим редактированием.

## Импорт правил

Панель инструментов → импорт CSV, XLSX или JSON. Проверьте импортированные строки в таблице перед предпросмотром применения.

## Workflow применения

1. Внести изменения в черновик
2. **Предпросмотр применения** — просмотреть запланированные команды и сводку diff
3. **Подтвердить** — выполнение по SSH (отклонено, если удалённый UFW изменился с момента предпросмотра — запустите предпросмотр снова)
4. Следите за баннером операции для прогресса

Подробности см. в [Workflow черновика и применения](../concepts/draft-apply-workflow.md).

## Советы по безопасности

- Всегда оставляйте хотя бы одно правило, разрешающее SSH из вашей админ-сети, перед применением deny-правил
- Запускайте предпросмотр в production в окне обслуживания
- Проверяйте **Историю операций** после применения на статус SUCCESS или FAILED
