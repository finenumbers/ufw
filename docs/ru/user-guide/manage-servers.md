# Управление серверами

Это руководство описывает жизненный цикл сервера: добавление, настройка UFW, обновление, редактирование и удаление.

## Предварительные требования

Создайте хотя бы одну [SSH-идентичность](../concepts/ssh-identities.md) перед добавлением сервера.

## Добавление сервера

1. Боковая панель → **Серверы** или нажмите **Добавить сервер**
2. Заполните имя, хост, порт и выберите идентичность
3. Нажмите **Создать сервер** — тест SSH выполняется автоматически
4. При успехе вы попадаете на панель сервера

Если тест SSH не проходит, проверьте доступность хоста, учётные данные, firewall (SSH с Docker-хоста разрешён) и [валидацию хоста](../concepts/servers-and-ssh.md).

## Панель сервера

Панель загружает **кэшированное состояние UFW** из последнего snapshot Postgres — без SSH при первой отрисовке. Страница остаётся быстрой.

| Статус | Доступные действия |
|--------|-------------------|
| UFW не установлен | **Установить UFW** |
| Установлен, но неактивен | **Включить UFW** |
| Установлен и активен | **Правила**, обновить, тест SSH |

Используйте **Обновить**, чтобы получить последнее состояние UFW по SSH и синхронизировать таблицу правил.

Если UFW активен, но у приложения **ещё нет snapshot** (первый визит после включения), один раз автоматически выполняется фоновая синхронизация для заполнения кэша.

## Редактирование сервера

1. Открыть сервер → **Редактировать**
2. Изменить имя, хост, порт или идентичность
3. Тест SSH обязателен перед сохранением, если изменились параметры подключения

## Удаление сервера

**Опасная зона** на странице редактирования или в настройках сервера:

- Удаляет все локальные правила, черновики и snapshots для этого сервера
- **Не изменяет** удалённый UFW

Подтверждайте только если хотите удалить данные управления, а не очистить удалённые правила firewall.

## Инструменты списка серверов

На главной странице серверов вы можете:

- **Сохранить конфигурацию** / **Загрузить конфигурацию** — полный JSON export/import (см. [Импорт и экспорт конфигурации](../concepts/import-export-config.md))
