# Управление серверами

Это руководство описывает жизненный цикл сервера: добавление, настройка UFW, обновление, редактирование и удаление.

## Предварительные требования

Создайте хотя бы одну [SSH-идентификацию](../concepts/ssh-identities.md) перед добавлением сервера.

## Добавление сервера

1. Боковая панель → **Серверы** или нажмите **Добавить сервер**
2. Заполните имя, хост, порт и выберите идентификацию
3. Нажмите **Создать сервер** — проверка SSH выполняется автоматически
4. При успехе вы попадёте на панель управления сервером

Если проверка SSH не проходит, проверьте доступность хоста, учётные данные, разрешает ли межсетевой экран SSH с Docker-хоста, и [проверку хоста](../concepts/servers-and-ssh.md).

## Панель управления сервером

Панель показывает статус UFW:

| Статус | Доступные действия |
|--------|-------------------|
| UFW не установлен | **Установить UFW** |
| Установлен, но неактивен | **Включение UFW** |
| Установлен и активен | **Правила**, обновление статуса, проверка SSH |

Используйте **Обновить статус**, чтобы получить актуальное состояние UFW и синхронизировать таблицу правил.

## Редактирование сервера

1. Откройте сервер → **Изменить**
2. Измените имя, хост, порт или идентификацию
3. Проверка SSH требуется перед сохранением, если изменились параметры подключения

## Удаление сервера

**Опасная зона** на странице редактирования или в настройках сервера:

- Удаляет все локальные правила, черновики, снимки для этого сервера
- **Не** изменяет удалённый UFW

Подтверждайте только если вы хотите удалить данные управления, а не очистить удалённые правила межсетевого экрана.

## Инструменты списка серверов

На главной странице серверов вы можете:

- **Сохранить конфигурацию** / **Загрузить конфигурацию** — полный экспорт/импорт JSON (см. [Импорт и экспорт конфигурации](../concepts/import-export-config.md))
