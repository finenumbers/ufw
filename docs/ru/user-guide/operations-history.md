# История операций

Длительные задачи (применение, обновление, установка UFW, проверка SSH) отслеживаются в **журнале операций** и отображаются в интерфейсе.

## Баннер операций

Пока операция выполняется, в верхней части приложения появляется баннер:

- Тип операции и статус (RUNNING, SUCCESS, FAILED)
- Разворачиваемый список шагов со статусом каждого шага
- Автоматическое закрытие при успехе через короткую задержку

Баннер опрашивает обновления, пока работа выполняется.

## Страница операций

Боковая панель → **История операций** (`/operations`)

Две вкладки:

| Вкладка | Содержимое |
|---------|------------|
| **Журнал операций** | Технический журнал операций — применение, синхронизация, проверка SSH и т.д. |
| **События аудита** | События, значимые для безопасности — вход, выход, экспорт конфигурации |

Обе поддерживают бесконечную прокрутку для более старых записей.

## Типы операций

Примеры:

- `apply_rules` — применение UFW
- `ufw_refresh` — обновление статуса и правил
- `ufw_sync` — синхронизация черновика с сервером
- `ufw_install` / `ufw_enable` — настройка UFW
- `ssh_test` — проверка подключения
- `server_create` — добавлен новый сервер

## Очистка истории

Администраторы могут очистить старую историю операций из интерфейса (события аудита могут сохраняться согласно политике хранения). Очистка не влияет на состояние серверов или правила.
