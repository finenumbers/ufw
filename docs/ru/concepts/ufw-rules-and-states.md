# Правила UFW и состояния

Правила нормализуются в единую модель строк с **основными** полями (важными для UFW) и **UI**-полями (имя, группа, цветовые метаданные).

## Основные поля правила

Типичные столбцы включают action (allow/deny/reject), direction, protocol, ports, source/destination addresses и режим логирования. Точный набор соответствует выразительному синтаксису правил UFW — см. таблицу правил в интерфейсе.

## Состояния синхронизации (цвета строк)

У каждой строки есть **состояние**, показывающее, как локальный черновик соотносится с последним снимком сервера:

| Состояние | Значение |
|-----------|----------|
| **MATCHED** | Черновик совпадает с тем, что UFW сообщил на сервере |
| **REMOTE_ONLY** | Есть в снимке сервера, но отсутствует в локальном черновике |
| **LOCAL_ONLY** | Есть в черновике, но отсутствует на сервере (будет добавлено при применении) |
| **DRAFT_ONLY** | Локальное изменение ещё не применено; отличается от согласованной базовой линии |

Цвета помогают заметить расхождение до применения. После **Принудительной синхронизации с сервером** локальный черновик выравнивается по удалённому состоянию.

## Отпечатки (fingerprints)

У каждого правила есть отпечаток, вычисленный из основных полей. Используется для сопоставления строк между снимками и определения операций изменения порядка/удаления при планировании применения.

## Группировка и порядок

- **Группы** — визуальная организация правил; имя группы — UI-метаданные
- **Порядок** — порядок правил UFW важен; изменение порядка при применении может потребовать удаления и повторного создания на сервере

## Форматы импорта

Правила можно импортировать из **CSV**, **XLSX** или **JSON** через панель инструментов правил. Импортированные строки становятся записями черновика — для попадания на сервер всё равно требуется применение.
