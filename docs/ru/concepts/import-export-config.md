# Импорт и экспорт конфигурации

Вы можете экспортировать и импортировать **полную конфигурацию серверов** (все серверы, идентификации, метаданные правил) в формате JSON **v2**.

## Экспорт

1. На странице **Серверы** используйте **Save configuration**
2. Повторно введите **пароль учётной записи** (step-up аутентификация)
3. Скачайте JSON-файл

### Важное предупреждение безопасности

Файл экспорта содержит **SSH-пароли и приватные ключи в открытом виде**. Относитесь к нему как к секрету:

- Храните в зашифрованном виде (хранилище менеджера паролей, зашифрованный диск)
- Никогда не коммитьте в git и не передавайте по незащищённым каналам
- При успешном экспорте записывается событие аудита `CONFIG_EXPORT`

## Импорт

1. Используйте **Load configuration** на странице Серверов
2. Выберите JSON v2 файл
3. Просмотрите сводку: серверы для создания, обновления, удаления
4. Подтвердите — импорт выполняется в транзакции (upsert сначала, delete в конце)

### Деструктивное поведение

Серверы, **отсутствующие** в файле импорта, могут быть **удалены** вместе со всеми их правилами и снимками. Внимательно читайте диалог подтверждения.

Импортированные SSH host keys могут быть помечены как **unverified**, пока вы не выполните SSH test на каждом сервере.

### Ограничения импорта

- Импорт правил (CSV, XLSX, JSON) ограничен **10 000 строк** на файл.
- **Предпросмотр** импорта конфигурации ограничен **10 попытками в минуту** на пользователя — подождите и повторите, если достигли лимита.

## Экспорт конфигурации vs резервная копия Postgres

| Метод | Содержимое | Лучше всего для |
|-------|------------|-----------------|
| **Экспорт конфигурации (JSON)** | Человекочитаемая конфигурация + секреты в открытом виде | Миграция между экземплярами, аварийная копия |
| **Дамп Postgres** | Полная БД, включая зашифрованные секреты | Полное восстановление с тем же `APP_ENCRYPTION_KEY` |
| **Резервная копия `.env`** | Секреты runtime | Необходима для расшифровки учётных данных БД после восстановления |

Для полного аварийного восстановления резервируйте **и** Postgres, **и** `.env` — см. [Резервное копирование и восстановление](../operations/backup-restore.md).
