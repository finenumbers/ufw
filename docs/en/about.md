## About the product

Finenumbers builds operational tools for infrastructure and communications teams. UFW Remote Manager addresses a practical need: centralized, auditable UFW management across Linux servers without logging into each host for every rule change.

The application is **self-hosted** — your data, SSH credentials, and firewall rules stay on infrastructure you control.
